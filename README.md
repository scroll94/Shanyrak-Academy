# Шаңырақ Code

Сайт онлайн-школы для подростков 14–18 лет: программирование и ИИ, математика, создание игр. Первый урок бесплатный, заявки уходят в WhatsApp.

Адрес: **https://scroll94.github.io/Shanyrak-Academy/**

## Идея

Школа оформлена как запуск видеоигры. Три направления — классы персонажа на экране выбора (Кодер, Математик, Геймдизайнер). Юрта, которая собирается при прокрутке, — первый уровень с квестами. Бесплатный урок — кнопка «Старт».

## Что на странице

1. Плакат «Нажми старт» с вращающимся 3D-шаңыраком.
2. Выбор класса: карточка персонажа с роликом, характеристиками, проектом и кнопкой записи; 3D-эмблема выбранного класса выходит вперёд.
3. Уровень 1: 3D-юрта собирается поверх ночной фотографии, квесты закрываются по мере сборки.
4. Огромная кнопка «СТАРТ» открывает WhatsApp.
5. Подвал как обратная сторона картриджа.

## Файлы

- `index.html` — вся страница.
- `assets/` — ролики направлений (сделаны в Remotion), постеры и фотографии из Wikimedia Commons (авторы в подвале).

Цвета: угольный фон и чистые цвета (красный, синий, бирюзовый, жёлтый). Шрифты: Tektur, Golos Text, Press Start 2P. Библиотеки: Three.js и GSAP с CDN.
