# Шаңырақ Code

Сайт онлайн-школы для подростков 14–18 лет. Три направления: программирование и ИИ, математика, создание игр. Первый урок бесплатный, заявки уходят в WhatsApp.

Адрес сайта: **https://scroll94.github.io/Shanyrak-Academy/**

## Что на странице

1. Первый экран с вращающимся 3D-шаңыраком.
2. Три направления. В каждой карточке короткое зацикленное видео, что ты будешь делать, твой проект и кнопка записи в WhatsApp.
3. 3D-юрта, которая собирается из деталей при прокрутке.
4. Запись на бесплатный пробный урок: форма открывает WhatsApp с готовым текстом.

Оформление светлое: белые карточки, у каждого направления свой цвет (синий, бирюзовый, коралловый), золото только у 3D-шаңырақа. Шрифты Rubik и Golos Text.

## Файлы

- `index.html` — вся страница: разметка, стили и скрипты.
- `assets/` — видео и постеры для карточек направлений. Они сделаны в Remotion (исходники в отдельной папке `shanyrak-videos`).

Библиотеки подключаются с CDN: Three.js и GSAP (только для сборки юрты при прокрутке), шрифты Google Fonts.

## Как опубликовать

Settings → Pages → Deploy from a branch → ветка **main**, папка **/ (root)** → Save.
