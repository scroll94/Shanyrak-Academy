# Шаңырақ Code

Сайт школы искусственного интеллекта и программирования для подростков 14–18 лет. Направления: создание игр, игры в Roblox, чат-боты, красивые 3D-сайты, приложения, 3D-моделирование и честная работа с ИИ.

Оформление в казахском стиле: золотой 3D-шаңырақ, орнамент «қошқар мүйіз», огненный беркут, юрта, которая собирается из деталей при прокрутке.

Адрес сайта после публикации: **https://scroll94.github.io/Shanyrak-Academy/**

## Как опубликовать

1. Откройте в репозитории **Settings → Pages**.
2. В поле **Source** выберите **Deploy from a branch**.
3. Ветка **main**, папка **/ (root)**, нажмите **Save**.
4. Через одну-две минуты сайт откроется по адресу выше.

## Что внутри

- `index.html` — весь сайт в одном файле: разметка, стили и скрипты.
- Библиотеки подключаются с CDN, устанавливать ничего не нужно: Three.js (3D-сцены), GSAP (анимации при прокрутке), Lenis (плавная прокрутка), шрифты Google Fonts (Unbounded, Onest, Cormorant).

## Разделы страницы

1. Шапка с вращающимся 3D-шаңыраком.
2. Беркут поднимается из огня, машет крыльями и выпускает семь направлений.
3. Карточки направлений с мини-анимациями и 3D-иконками.
4. 3D-юрта: кереге, уықтар, шаңырақ и войлок появляются по очереди.
5. Как проходит обучение, казахская пословица, пять правил честного ИИ.
6. Частые вопросы и форма записи на пробный урок.

## Как поменять тексты

Откройте `index.html` в любом редакторе кода, например в VS Code, найдите нужный текст и замените его. Чтобы проверить результат, откройте файл в браузере. После сохранения изменений в репозитории сайт обновится сам.

Форма записи пока не отправляет заявки на сервер: она собирает текст заявки, который посетитель копирует и отправляет преподавателю.
